# DexpDock

Утилита для Windows для мыши **DEXP GS Slayer Pro** и её 8K-дока.

- Управление подсветкой дока: режимы, цвет, скорость, яркость.
- Подсветка дока может повторять цвет текущей ступени DPI мыши (работает и с открытой, и с закрытой заводской программой GS_Slayer Pro)
- Работа из системного трея (работа в трее нужна только для режима dpi).
- Русский и английский интерфейс.

Экран дока с ПК менять нельзя: для этого нужно вскрыть прошивку, а ДНС отказались предоставлять мне открытый код дока, если когда-нибудь найду его SDK то доделаю прогу.

## Установка и запуск

1. Скачайте [`DexpDock.zip`](DexpDock.zip) и распакуйте.
2. Нужен Python 3.9+ для Windows (сторонние библиотеки не требуются).
3. Запустите `start.bat` (окно) или `start-tray.bat` (сразу в трей).

Подробное описание, команды и протокол — в `README.md` внутри архива.

Тесты: `python -m unittest discover -s tests -t .`

## Предупреждение

Проект неофициальный и не связан с DEXP. Программа не пишет настройки в память мыши и не трогает прошивку, но вы используете её на свой риск.
